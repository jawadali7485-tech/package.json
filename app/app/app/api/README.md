# ✦ NOVA AI

## Ask. Create. Get It Done.

NOVA AI is an all-in-one AI assistant designed to help users with everyday questions, creativity, writing, career documents, coding, research, and more.

## Features

- 💬 AI Chat
- 🎨 Image Generation
- 🖼️ Image Analysis
- 💡 Idea Generator
- ✍️ Prompt Generator
- 🎬 Script Writer
- 📄 CV / Resume Builder
- ✉️ Cover Letter Generator
- 📧 Email Writer
- 📎 PDF & File Analysis
- 💻 Coding Assistant
- 🌐 Web Research
- 🎤 Voice Assistant
- 🧠 Conversation Memory
- 📚 Chat History

## Vision

One powerful AI assistant for work, creativity, learning, and productivity.

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
- OpenAI API

## Security

Never expose your API key in frontend code or commit private API keys to GitHub.
